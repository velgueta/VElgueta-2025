Detection correspondence between DAS and conventional seismic stations over the common interval 23 August 2023 21:00 UTC to 22 November 2023 00:00 UTC (end exclusive). ML picks are PhaseNet-DAS for DAS and ELEP for stations; all ML associations use GaMMA. All temporal comparisons use one-to-one assignments within ±7 seconds, maximizing the number of matches and then minimizing summed absolute time differences.
(a) Recovery of 216 ComCat earthquakes with epicenters within 25 km of the original Rainier reference-query center (46.879967° N, 121.726906° W). DAS TM, DAS ML, station TM, five-station ML and full-network ML recover 53, 152, 62, 124 and 208 reference events, respectively. N gives the full selected method catalog, not just its ComCat counterparts: 85, 478, 92, 266 and 1,383 records. No additional ML location gate is applied when evaluating ComCat recovery.
(b) Direct temporal comparison of TM and ML using complete selected catalogs, without requiring a ComCat counterpart or restricting estimated epicenters. DAS: 39 TM only + 46 matched pairs + 432 ML only = 517 in the union; the original totals are TM 85 and ML 478. Stations: 55 TM only + 37 matched pairs + 229 ML only = 321 in the union; the original totals are TM 92 and five-station ML 266. A matched pair is counted once in the union. The station comparison is not a controlled five-station TM versus five-station ML experiment because the TM production station subset is unverified.
(c) Direct temporal comparison of complete selected DAS ML and five-station ML catalogs, without requiring ComCat correspondence or a location/radius gate. There are 117 matched pairs, 361 DAS-only records and 149 five-station-only records. Thus the separate bars reproduce the original catalog totals: DAS 117 + 361 = 478 and five stations 117 + 149 = 266. The 117 matched pairs are shown in both bars because each bar represents one input catalog; they should be counted once in a combined union (627 records/pairs). Panels (b) and (c) use independent assignments and are not a global event partition across all methods.
The DAS selection links 478 of 483 historically reviewed and consolidated groups to the updated GaMMA catalog, including 138 uncertain links; five groups have no assigned new record and are excluded. New-run locations were not independently re-reviewed. The raw DAS association has 942 candidates. TM DAS selection is CC >0.07; station-TM production stations are unverified and cannot be assumed to be the same five stations. The five-station ML records are accepted as valid by study assumption. TM uses maximum-correlation detection times, ML uses stored origin times; neither a reference-time conversion nor DAS drift correction has been applied. Common calendar dates do not imply identical data availability. ComCat is not an exhaustive earthquake reference. Unmatched detections do not establish distinct physical earthquakes. The figure measures temporal correspondence, not false-positive rates or location accuracy.
